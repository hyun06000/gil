artifacts only, not unrelated conversation, file-free research or other projects.

adding charts/images to an existing report), call `gil_context` with this project's
actual absolute root. Read the recorded position and current contract before any
file-producing tool. Do not use `gil_start` for an existing project.

alone does not require a new Cycle. Never backfill work already done or invent approval.

do not silently continue untracked, repair `.gil`, or create replacement records.
