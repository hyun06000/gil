# 시나리오 실행 결과

날짜별 일회성 실행 산출물은 소스와 분리해 보관한다. 기존 실행 기록은
[정리 전 이력](https://github.com/hyun06000/gil/tree/a992efa43c10ef4dc3ad97699cb504663d07288a/scenarios/wave1/runs)에 남아 있다.
재현 가능한 시나리오·fixture·runner·평가 시험은 계속 유지한다.

[실행기](../../../tools/scenarios/README.md)의 `--out <저장소 밖 임시 경로>`로
`wire-run.json`, `wire-run.md`, `wire-events.jsonl`, `wire-frames.jsonl`을 저장한다.
토큰·임시 경로 가림과 누출 검사를 통과한 자료만 검토·공유하며, 제품 릴리즈의 검증 결과는 해당
게시 장부와 릴리즈 자산에 연결한다. 원시 프레임이나 중복 실행 로그를 소스에 추가하지 않는다.

프로토콜 결과는 실제 사람의 승인·Host 화면·모델 평가 결과와 구분한다.
