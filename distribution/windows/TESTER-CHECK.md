# Windows 테스터 확인표

Windows unsigned 시험판과 [설치 안내](INSTALL.md)가 게시되었습니다. Mac용 안내를 대신
따라 하지 않습니다. 실제 Windows 사용자 설치와 화면 확인은 이번 검수의 대상입니다.

## 누구를 위한 시험인가요?

- Windows PC와 Codex 앱을 사용하는 분. 개발 경험은 필요하지 않습니다.
- CPU 종류를 직접 조사할 필요는 없습니다. 설치 도구가 자동 확인하고 게시된 호환 패키지를
  선택합니다. 감지 실패나 지원하지 않는 환경이면 설치하지 않고 쉬운 말로 이유를 안내합니다.
  자동 감지와 실제 설치 완료는 다릅니다. Agent가 설치 안내에 따라 환경을 확인합니다.
- 아직 서명 없는 시험판입니다. 중요한 자료 대신 새 빈 폴더에서 시작합니다.
- Node·Rust 같은 개발 도구나 별도 GIL Companion 설치는 필요하지 않습니다.
- 보안 경고가 나오면 중단하고 알려주세요. 보안을 끄거나 관리자 권한으로 우회하지 않습니다.

## 설치가 끝나면

1. Codex에서 새 대화를 열고 시험할 빈 로컬 폴더를 선택합니다. OneDrive·네트워크 폴더는
   피해주세요. 폴더 선택이 어렵다면 어디서 막혔는지만 알려주면 됩니다.
2. 아래 문장을 보냅니다.

   > 지금 선택한 빈 폴더에서 GIL 프로젝트를 시작해 줘. 간단한 계산기를 만들고 싶어.
   > GIL Monitor를 열어 그래프를 보면서 이야기할 수 있게 해 줘.
   > 필요한 내용은 나에게 하나씩 물어봐 줘.

3. 그래프와 채팅 입력창이 함께 보이는지 확인합니다. 노드를 눌러 상세 내용도 확인합니다.
4. 계산기를 만드는 동안 그래프가 저절로 바뀌는지 봅니다.
5. 진행 중인 작업이 끝난 뒤 Codex를 완전히 종료하고 다시 엽니다. 같은 대화로 돌아와
   그래프가 다시 보이는지 확인합니다. 선택·접힘이 완벽하게 같지 않다면 그 점만 기록합니다.

## 알려주실 것은 네 가지뿐입니다

- 설치: 성공 / 막힘
- 그래프와 채팅 함께 보기: 성공 / 막힘
- 노드 상세와 자동 갱신: 성공 / 막힘
- 앱을 껐다 켠 뒤 다시 보기: 성공 / 막힘

불편하거나 헷갈렸던 말도 편하게 알려주세요. 오류가 있다면 문구 또는 개인정보를 가린
스크린샷이면 충분합니다. 터미널 로그나 프로젝트의 `.gil` 폴더를 보내지 않아도 됩니다.
Agent가 “열었다”고 말한 것과 실제로 그래프가 보인 것은 구분해서 알려주세요.

제거·재설치 검수는 첫 실행 결과를 확인한 후 별도로 안내합니다. 삭제할 때에도 프로젝트
폴더나 `.gil`을 지우지 않습니다. 이 문서는 실제 Windows 사용자 검수가 끝났다는 증거가 아닙니다.
