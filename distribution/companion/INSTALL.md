# GIL Companion + Core 설치 안내 — 제작 중

**아직 실행 가능한 사용자 설치 안내가 아닙니다.** 이 문서는 새 사용자 설치 경로의 정본 초안입니다.
Companion＋Core 통합 installer와 공식 Codex 연결 인수가 완료되기 전에는 설치 완료를 주장하거나
이 문서를 근거로 기존 Plugin을 제거하지 마세요. 현재 게시된 runtime-verify 묶음은 설치 프로그램이 아닙니다.

## 사용자 경로

1. 공식 다운로드 페이지에서 Windows/Mac, CPU, 버전, 시험판/서명 상태를 확인합니다.
2. 해당 OS용 Companion＋Core 설치 프로그램을 받습니다.
3. 설치 프로그램에서 변경 내용을 읽고 설치를 승인합니다. OS가 차단하면 안내를 보존하고 멈춥니다.
4. 설치 프로그램이 안내하는 **검수된 공식 Codex 연결 절차**를 완료합니다.
5. Codex에서 GIL을 요청해 실제 응답의 버전과 빌드를 확인합니다.
6. GIL Project를 열면 Windows 트레이/Mac 메뉴 막대에 관리 아이콘이 나타나야 합니다.

다운로드 페이지, 자산명, 전체 hash, 서명 검증 방법, Codex 연결 절차는 release마다 완성한 뒤
게시해야 합니다. 현재는 미확정이며 URL이나 명령어를 추측해서 채우지 않습니다.

## Codex에 요청하는 보조 경로

게시 준비가 끝나면 사용자는 공식 다운로드 페이지와 이 문서의 URL을 포함해 다음처럼 요청합니다.

> 공식 GIL 설치 안내에 따라 Companion과 Core 설치를 도와줘. 실행 전에 설치 대상과 변경 내용을
> 알려주고, 내가 해야 하는 설치 프로그램 실행·OS 승인은 구분해 줘. 실패하면 설정을 고치지 말고 멈춰 줘.

Agent의 절차:

- OS와 **기계 CPU**를 확인합니다. 프로세스 아키텍처만으로 추측하지 않습니다.
- 같은 release의 안내·묶음·무결성·publisher 신뢰 정보를 대조합니다. hash 일치는 출처 인증이 아닙니다.
- 새 설치인지 기존 설치가 있는지 읽기 전용으로 확인합니다. 다른 프로젝트와 기록을 열지 않습니다.
- 변경 범위와 다운로드 위치를 설명합니다. 다운로드 등 네트워크 승인은 공식 승인 절차만 사용합니다.
- 공식 installer가 없다면 **설치 경로 미준비**로 멈춥니다. 긴 스크립트 생성, plugin cache 삭제,
  config.toml 손편집, 보안 경고/실행 정책/ACL/상속 변경, 관리자 실행으로 대체하지 않습니다.
- 사용자가 해야 하는 클릭·OS 승인을 안내하고 그 뒤 실제 Core 응답으로 설치를 확인합니다.
  등록 성공·버전 파일 존재·도구 수만으로 완료하지 않습니다.

## 이후 업데이트

GIL 사용 중 관리 아이콘 → 업데이트 안내 → 대상 버전·변경점 확인 → 사용자가 업데이트 시작.
Agent는 안내와 적용 확인만 합니다. 기존 연결은 기존 Core를 유지하며 새 연결부터 새 버전을 사용합니다.
마지막 연결이 끝나면 Companion도 종료합니다. 진행 중인 업데이트만 완료/실패 기록 뒤 종료합니다.
자동으로 Project 저장 형식을 이관하거나 구버전을 삭제하지 않습니다.

## 게시 전 작성자가 반드시 채울 항목

- OS/CPU별 설치 자산과 정확한 release/build identity, download URL, 크기·전체 digest
- 서명·공증/Windows publisher 확인 절차 및 지원 여부 (미지원은 명시)
- 신규 설치·기존 설치 감지·취소·실패·제거·전체 설치 업데이트 절차
- 실제 공식 Codex 연결 화면/절차와 새 연결의 버전 확인 방법
- 동일 묶음의 Companion/Core/launcher/Skill 호환성, 최초 설치와 업데이트 인수 결과
- Core 옆 `companion-install.json`의 protocol·고정 Companion 파일명·전체 digest와 실제 cohort
  배치. 이 파일은 installer가 생성/검증하며 사용자가 직접 만들도록 요구하지 않는다.
  기존 Plugin에는 기록을 소급해서 추가하지 않는다. receipt 일치는 publisher 서명을 대신하지 않는다.
