# 승인·중단 안내와 복구 보존 보강 시험판 — 2026-11-17

macOS Apple Silicon `0.2.1-preview.31`을 GitHub 프리릴리즈로 게시했다.
사용자는 설치 파일 제작·프리릴리즈 배포를 요청했고 **필드 테스트는 직접 진행**하기로 했다.
기존 플러그인·앱 설정·사용자 프로젝트는 변경하지 않았다. Windows는 기존 v0.3.2를 유지한다.

## 포함 범위

- 입력 오류와 승인 대기의 다음 행동을 구분하고 불필요한 반복 도움말 조회를 줄이는 안내.
- 보고서의 관측·해석 구분, 검증 미완료의 정직한 기록, 중단 시 부분 결과 우선 제시.
- 수동 복구 승인 출처 기록, 원본 보존·보호 경로 거절·재시작·중복 호출 회귀 시험.
- 기존 간결한 모니터·보고서, 결과물 우선 종료 인터뷰, 다섯 언어 지원 유지.
- `.gilignore` 인터뷰는 설계 제안이고 자동 복구는 제품에서 비활성이다. 설정 입력 경로·저장 형식 확정,
  부분 결과를 작업 폴더에 둔 채 재계획하는 기능은 후속이다. 측정·문서 연결 도구는 개발용이다.

[소스 통합 요청 #132](https://github.com/hyun06000/gil/pull/132)에 원본 #125–#131의 이력과
통합 중 발견한 파일 덮어쓰기·복구 시험 충돌 보완 및 검증 결과가 있다.

## 검증 범위

- 소스 통합 최종 커밋의 Mac·Windows·Companion 6개 자동 검사와 병합 후 main 검사가 성공했다.
- 이번 후보 제작은 approved-plan·visual-authoring·product-safety 제품 구성의 회귀, 기본 Core 전체 대상 빌드,
  화면·플러그인·포장·라이선스 고지·문서 연결·측정 도구 검사를 통과했다.
- 원격 제작에서 정확한 버전, 33개 도구, 내장 화면, 새 프로세스 응답, 압축 왕복 검사를 통과했다.
- 로컬에서 배포 원본 해시·안전한 압축 멤버·영수증을 확인했다. 배포 무결성·이력 개인정보 시험 29개 통과.
- preview.30과 preview.31로 각각 만든 임시 합성 프로젝트에서 30 → 31 → 30 → 31로 문맥을 읽었다.
  프로젝트마다 6개 파일의 내용이 그대로였다. 시작·읽기 호환 검사이며 복구 이력의 하위 버전 호환이나
  실제 앱 업데이트·복구 인수를 입증하지 않는다. `migration: requires_review`를 유지한다.
- 새 원본 압축 파일을 지정한 Git 없는 준비 경로를 포함해 포장·고지 시험 106개 통과.
  첫 실행에서 이전 판의 문자열 기대값 한 곳이 검출돼 버전 기대값을 갱신한 뒤 전체 재실행했다.
  이 준비 경로는 임시 디렉터리로 압축만 해제하며 앱에 등록하지 않았다.

## 사용자 필드 테스트

실제 Codex·Claude 설치, 모델의 안내 준수, 모니터 판독·전체 화면·재연결, 새 Mac 최초 실행,
실제 프로젝트의 업데이트·복구는 **사용자 확인 대기**다. 이전 버전의 화면 인수를 이번 판으로 승계하지 않는다.
Apple 개발자 서명·공증은 없다. 사용자 검수를 대신 실행하거나 사용자 프로젝트를 시험 데이터로 쓰지 않았다.

[Mac 설치 안내](INSTALL.md)는 고정 버전·공개 파일 해시·기존 설치 교체·직전 preview.30 복구를 안내한다.
[루트 안내](../../INSTALL.md)와 [상세 안내](../INSTALL-GUIDE.md), Git 없는 준비 스크립트·업데이트 피드·로드맵도 같은 버전을 따른다.
