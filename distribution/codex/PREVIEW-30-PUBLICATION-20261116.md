# 간결한 모니터·보고서 시험판 — 2026-11-16

macOS Apple Silicon `0.2.1-preview.30`을 GitHub 프리릴리즈로 게시했다.
사용자는 문서 반영과 게시까지 승인했으며, **기존 설치본 적용은 보류**했다.
플러그인 캐시·앱 설정·사용자 프로젝트는 변경하지 않았다.

## 변경

- 현재 작업·진행·다음 행동 중심의 모니터, 접힌 상세 기록, 중복 문구 축소.
  승인 버튼·오래된 상태 경고·불확실한 결과는 유지한다([PR #122](https://github.com/hyun06000/gil/pull/122)).
- 짧은 보고서와 작업물 우선 종료 인터뷰 안내. 근거·실패·불확실성은 생략하지 않는다
  ([PR #121](https://github.com/hyun06000/gil/pull/121)).
- 다섯 언어 지원을 Mac 공개판에 포함한다([PR #112](https://github.com/hyun06000/gil/pull/112)).
- 실행 환경 전환의 동시성 시험 기대값 보정은 시험 수정이며 제품 동작 변경이 아니다
  ([PR #123](https://github.com/hyun06000/gil/pull/123)).
- `.gilignore`, 실패 복구 자동 승인, 여러 실험 동시 진행 등 후순위 명세를 구현했다고 주장하지 않는다.

[프리릴리즈](https://github.com/hyun06000/gil-marketplace/releases/tag/v0.2.1-preview.30)에
자동 검사가 만든 압축 파일·SHA256SUMS·checks.json·update-record.json을 원본 그대로 첨부했다.
로컬 검토용 빌드는 게시하지 않았다. 기존 버전 자산을 덮어쓰거나 정식 최신판으로 지정하지 않았다.
게시 후 인증 없는 공개 주소에서 네 파일을 다시 내려받아 자동 검사 원본과 바이트가 같음을 확인했다.
제작 영수증의 `publishable:false`와 신뢰 필드는 보존하며, 게시 승인은 검토 요청·릴리스·이 장부에 남긴다.

두 저장소의 main 보호를 재조회했다. 최신 main 반영과 각 필수 검사를 요구하고 관리자에게도 적용하며,
필수 사람 리뷰 수는 0이다. main 직접 올리기·강제 덮어쓰기·보호 규칙 우회를 사용하지 않았다.

## 검증 범위

- 최신 소스 기본 Core 시험 1,621 통과·기존 2 제외, 모든 Core 대상 빌드 성공.
  제품 기능 조합 시험 785 통과·기존 1 제외. 화면·플러그인·패키징 통합 시험 303 통과·기존 6 건너뜀.
- 첫 기본 시험은 이전 기능 조합이 남긴 같은 이름의 임시 기록 때문에 실패했다.
  `/private/tmp` 분리 재실행도 Mac 경로·권한 전제를 만족하지 못했다. 운영체제의 원래 임시 경로 아래
  새로운 시험 폴더를 기능 조합별로 분리한 뒤 전체 시험이 통과했다. 제품 코드나 검증 조건을 약화하지 않았다.
- 원격 후보 제작은 한 번에 성공했다. 정확한 버전·33개 도구·내장 화면·압축 왕복·고지를 검사했다.
  실제 게시 원본의 해시·안전한 압축 멤버·제작 영수증을 로컬에서도 확인했다.
- 배포 무결성·이력 개인정보 회귀 시험 29개 통과. 첫 실행의 구버전 기대값 한 곳을 새 검수 버전으로
  바꾸고 전체를 재실행했다. 병합과 태그 이후에도 파일 무결성·GitHub 비공개 이메일 이력을 재확인했다.
- 설치 안내·핀·업데이트 피드를 맞춘 뒤 패키징·고지 시험 106개 통과, 건너뜀 없음.
  실제 게시 원본을 지정해 Git 없는 준비 경로의 정상 해제와 위조·손상·경로 이동 거절을 확인했다.
  중간 검사에서 아직 맞추지 않은 피드 버전 2건이 검출돼 게시 메타데이터를 정합시킨 뒤 재실행했다.
- 기존 Windows 게시 정보 정정과 관련된 설치 계약 시험도 17개 통과했다. Windows 실행 검수는 아니다.
- preview.29와 preview.30이 각각 만든 격리된 합성 프로젝트에서 29 → 30 → 29 → 30으로
  도구 서버를 재연결해 읽었다. 각 프로젝트 6개 파일의 내용이 모두 보존됐다.
  호환 범위는 동일하고 `migration: requires_review`는 유지한다. 정책 검사는 양방향 모두
  명시적인 계약·이관 검토를 요구한다. 이 검토와 읽기 시험은 실제 앱 설치·복구 인수가 아니다.

이번 버전의 실제 Codex·Claude 설치, 모델의 안내 준수, 모니터 판독·전체 화면, 새 Mac 설치와
앱 업데이트·이전 판 복구는 미검증이다. 이전 버전의 사용자 화면 확인을 새 판으로 승계하지 않는다.
Apple 개발자 서명·공증은 없고, 보안 기능을 해제해 실행하지 않는다.

## 함께 정리한 안내

[루트 설치 안내](../../INSTALL.md)에서 운영체제를 먼저 나누고, Mac의 고정 버전·다운로드·확인 값,
기존 설치 교체·이전 판 복구·실패 대응을 [Mac 정본](INSTALL.md)에 맞췄다.
Git 없는 안내의 구형 훅 등록 지시를 현재의 GIL 훅 제거 절차로 바로잡았다.
개발용 제작 지침·로드맵·업데이트 피드도 같은 게시 상태를 가리킨다.

Windows는 새로 배포하지 않았다. 이미 공개된 [v0.3.2](https://github.com/hyun06000/gil/releases/tag/v0.3.2)를
조회하고 내려받은 실행 파일과 체크섬을 대조해, 뒤처진 `current-release.json`·피드·설치 안내만 정정했다.
출처는 `46dee5c5ef4e77b78547b2d6b17f5071f696fa3a`,
[기존 제작 검사 43268869416](https://github.com/hyun06000/gil/actions/runs/43268869416)이다.
실행 파일은 11,885,056 bytes, SHA-256
`232a59435a13bc5c62616c7c6770db3fbcdafe502f57684c667b2c55ac316eb1`이며 이 Mac에서 실행하지 않았다.
