# 탐색형 체인 Mac 시험판 — 2026-11-19

macOS Apple Silicon `0.2.1-preview.32`를 [GitHub 프리릴리즈](https://github.com/hyun06000/gil-marketplace/releases/tag/v0.2.1-preview.32)로 게시했다.
사용자가 최신 기능까지 설치본에 포함한 뒤 게시하도록 승인했다. 기존 설치·설정·프로젝트는 변경하지 않았으며 필드 테스트는 사용자가 진행한다. Windows는 v0.3.2를 유지한다.

## 포함 범위와 호환성

- 승인 요구 아래 여러 작은 예·아니요 실험을 수행하는 `exploration-flow`를 명시적으로 포장한다.
- 요구 원문 화면, 연결 실험의 원본 보고서·저장 근거 조회, 근거와 한계를 제시하는 종료·인계 안내를 포함한다.
- 잠정 정리 저장소와 요구 자동 완료 판정은 없다. 사용자 종료 승인을 유지한다.
- 새 빈 테스트 프로젝트를 사용한다. 기존 체인은 자동 전환하지 않는다.
- 저장 형식 범위 4–7이 같아도 preview.31은 탐색 표식 기록을 거절한다. 설치본 되돌리기는 기록 변환이 아니다. 이번 실행 파일을 보존한다.
- 제품의 일반 복원·Step revisit 차단을 유지한다. 닫힌 실패 실험은 Monitor 변경 목록·보존·복구 승인 경로를 따른다. 자동 복구 승인은 제품에서 꺼져 있다.

## 검증과 한계

- 탐색 제품 구성 핵심 시험 781 통과·1 제외, 관련 통합 시험 20 통과. 기본 Core 전체 대상 빌드와 화면·플러그인·포장·고지·문서 연결 검사 통과.
- 로컬 패키징·고지·자동 검사 도구 시험 115 통과·1 제외. 로컬 개발 묶음 및 배포 후보의 실제 실행·압축 왕복 검사 통과.
- 원격 최종 후보에서 정확한 버전, 35개 도구, 새 프로젝트 탐색 계약, 내장 화면과 압축 왕복 확인.
- 배포 저장소 무결성·이력 시험 29 통과. 공개 네 파일의 원본 동일성 확인.
- 공개 원본을 지정한 Git 없는 준비 경로를 포함해 문서 갱신 후 포장·고지 시험 109건 통과. 이전 버전 문자열 기대값 한 곳을 갱신했다. 앱 등록 없이 임시 폴더 준비만 검사했다.
- 실제 앱 설치·모델 안내 준수·모니터 판독·전체 화면·재연결·새 Mac 인수는 사용자 확인 대기다. 이전 판의 인수를 승계하지 않는다.
- Apple 개발자 서명·공증은 없다. 운영체제 차단 우회를 하지 않는다. Companion 전용 검수 성공을 주장하지 않는다.
